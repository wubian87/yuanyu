# 原语言

> 把 [原语言.md](原语言.md) 整个丢给任何一个 AI，说「开始」。剩下的它会带你走。

## 这是什么

原语言是一门 AI 时代的语言：你不用它写程序，用它写**种子**——把一个还糊的想法，压成几行不变的东西，交给 AI 长成真物。

一颗种子是一个单文件，只钉三件事：

- **y** —— 不变的问题。拿走一切做法，你仍然要的那个东西。
- **验收** —— 怎么算解对了。只写"够到什么"，不写"别犯什么"。
- **押注** —— 往哪个方向解。不写长相，不写步骤。

外加一段**空气**：给将来长它的 AI 的关键背景，和你预见到的跑偏信号——它会长成第一层刹车。

种子是产出，但真正的产品是你：每跑完一颗，你就多会一次"什么该钉住、什么该放手"的判断。

## 语法：三个动词，一个测试

**开始**（糊想法 → 雏形）→ **归原**（雏形 → y）→ **出**（y → 种子）

**出厂**是编译测试：把种子——只有种子，不带你们的对话——交给至少两个不认识你的 AI，看它们能不能长出能用、又没走样的东西。能，说明你钉住的确实是承重的。

两份文件，分工不同：

## 种子园

种子出厂不是终点。种子园是它出厂后的成长家：一颗种子一块地，真用踩坑，疤回填成长记录——回疤跳小版本，动 y 跳大版本，成长记录只增不改。户口制度不是纸上规矩，是这么跑的。

园规见 [examples/种子园-园规.md](examples/种子园-园规.md)。
