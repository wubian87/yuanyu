# 原语言

> 把 [原语言.md](原语言.md) 整个丢给任何一个 AI，说「开始」；手上已经有东西要回炉（旧种子、被污染的种子、一段代码），说「归原」。剩下的它会带你走。

## 这是什么

原语言的「原」，是归原的原：剥掉一切做法，剩下你仍然要的那个东西——凝成种子，交给 AI 长成真物。**只帮人做会，不帮机器做对。**

你不用它写程序，用它写**种子**。一颗种子是一个单文件，只钉三件事：

- **y** —— 不变的问题。拿走一切做法，你仍然要的那个东西。
- **验收** —— 怎么算解对了。只写"够到什么"，不写"别犯什么"。
- **押注** —— 往哪个方向解。不写长相，不写步骤。

外加一段**空气**：给将来长它的 AI 的关键背景，和你预见到的跑偏信号——它会长成第一层刹车。

种子是产出，但真正的产品是你：每跑完一颗，你就多会一次"什么该钉住、什么该放手"的判断。

## 语法：三个动词，一个出厂

**开始**（糊想法 → 雏形，没有对象时的入口）→ **归原**（雏形或现成的东西 → y，回炉走同一刀）→ **出**（y → 种子）

**出厂**＝把种子送进成长家（种子园的收件）。从这往后是园里的事：门规、户口、农具管生长。想验种子承不承重（可选，不是关卡）：把种子——只有种子，不带你们的对话——交给两个不认识你的 AI 长一遍，能用又没走样，钉住的就是承重的。

## 真跑证据

这套东西不是想出来的，是跑出来的。[examples/](examples/) 里是三颗真种子，不是演示用的道具：
  - [手机探班.seed.md](examples/手机探班.seed.md) —— 一个 Web 终端桥。v1.3，三轮真用（本机两版 + NAS 应用化），成长记录里全是踩出来的疤。这颗种子长出的真物已开源：[probe](https://github.com/wubian87/probe)——种子和真物互为出厂证据。
  - [随身门.seed.md](examples/随身门.seed.md) —— 个人图书馆的手机入口。v1.1，含第一批回疤。真物已开源：[pocket-door](https://github.com/wubian87/pocket-door)。
  - [知常.seed.md](examples/知常.seed.md) —— 一个减脂记录工具的种子。v1.0 初立，示范"动了 y 就另立新种子"。

## 种子园

种子出厂不是终点。种子园是它出厂后的成长家：一颗种子一块地，真用踩坑，疤回填成长记录——回疤跳小版本，动 y 跳大版本，成长记录只增不改。户口制度不是纸上规矩，是这么跑的。

种子园的制度已开源（园规、园的种子、农具、养分堆）：[seed-garden](https://github.com/wubian87/seed-garden)。
